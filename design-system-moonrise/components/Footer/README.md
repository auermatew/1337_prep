# Footer

The end of the page: GitHub ↗, Transcripts and Notebook as a belt of white rules (1px `ink` lines above, below and between) sitting directly on the cropped `Wordmark`.

- Links are set large in the display face. On hover a cell fills `ink` with `on-ink` text.
- Provide `links: [{ label, href, onClick?, external? }]`. By default it's GitHub, Transcripts and Notebook.
- No logo and no tagline: the wordmark under it is the sign-off.
- On phones the three cells stay in one row at 15px.
