# Panel

The frosted glass surface everything floats on: `glass` fill, `blur-glass` backdrop blur, a 1px `line` border, `radius-m`. No drop shadows.

- `glow`: adds `glow-card`, a red edge and spill along the bottom. Only for things that are live (a running timer).
- `strong`: `glass-strong` and `radius-l`, for drawers and modals.
- Glass needs something behind it: place panels over the Scene (sky, clouds, moon), never on flat `sky-0` alone.
