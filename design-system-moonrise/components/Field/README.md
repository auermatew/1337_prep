# Field

An underline input with a small label above it and an optional hint after the value.

- Provide `id`, `label` and the usual input props. `hint` is muted text such as "= 3m"; `error` is a sentence in `alert` that says how to fix it.
- Label in `label` style and `ink-2`, value in `body-l` with tabular numerals, underline `line-strong`, turning `ink` and 2px on focus.
- No boxes, no floating labels, no uppercase.
