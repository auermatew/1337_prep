# ArchiveTable

Ended timers, newest first: name with short id, state, duration, end time, History.

- Provide `rows` (show 20), `total` for "Show all (n)", `openId` and `onToggleHistory(id)`.
- Finished in `moon`; cancelled in `ink-3` with the duration struck through. No checkboxes, brackets or badges.
- History opens as a popover under its button, over the rows below, so the table never moves. Rows without history show no History link.
- Rows divided by `line`; header labels in `label` style, sentence case. On phones each row stacks into two lines.
