# Nav

Transparent bar over the sky: the logo, plain text links, GitHub ↗ and the live indicator.

- Links, in this order: Timers, Archive, Transcripts, Notebook, GitHub ↗ (new tab). No numbers, separators, icons or uppercase.
- Under 720px the links fold into a "Menu" text button that opens a full-screen glass sheet; the live indicator stays visible.
- Never shown in the hero. It slides in as a sticky bar on `glass-strong` once the hero has scrolled away.
